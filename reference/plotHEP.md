# Plot a heartbeat-evoked potential

Plot a heartbeat-evoked potential

## Usage

``` r
plotHEP(x, main = "Heartbeat-evoked potential", ...)
```

## Arguments

- x:

  A `"hep"` object.

- main:

  Title.

- ...:

  Passed to
  [`graphics::plot()`](https://rdrr.io/r/graphics/plot.default.html).

## Value

`invisible(NULL)`.
