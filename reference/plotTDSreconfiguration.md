# Plot network reconfiguration across states

Heatmap of per-state node degree (states x nodes): how each system's
number of stable couplings changes across physiological states.

## Usage

``` r
plotTDSreconfiguration(x, main = "TDS network reconfiguration", ...)
```

## Arguments

- x:

  A `"tds_state"` object.

- main:

  Plot title.

- ...:

  Ignored.

## Value

`invisible(NULL)`.
