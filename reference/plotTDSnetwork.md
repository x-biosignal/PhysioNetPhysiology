# Plot a TDS organ-interaction network

Circular node layout; edge width and colour encode TDS strength.

## Usage

``` r
plotTDSnetwork(x, main = "TDS organ-interaction network", ...)
```

## Arguments

- x:

  A `"tds_network"` object.

- main:

  Plot title.

- ...:

  Ignored.

## Value

`invisible(NULL)`.
